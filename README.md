# 简表工具坊

## 两表编号与金额核对模板

这是简表工具坊制作的原创表格作品，当前版本为 **v0.3 Calc 版**。作品用于辅助检查两份编号与金额清单，分别提示金额差异、单边缺失、重复编号和无效输入，方便使用者回到原始记录逐项复核。

工作簿包含“核对总览”“表A”“表B”三个工作表。每表支持 200 行数据，填写编号和金额后，可在 I 列查看逐行结果，在总览查看汇总。

演示使用虚构数据，包含正常匹配、金额差异、重复编号、单边缺失、零金额和负金额等情况。

## 使用边界

本作品只比较输入的编号和金额，不判断交易真实性、漏导记录或会计正确性。重复编号需由使用者根据原始记录处理，不自动合并。

## 当前进度

已在本机 **LibreOffice Calc 26.8.1.1、macOS 27.0（Apple ARM）** 实测通过下列场景：样例金额修改联动、16 行异常组合、200 行容量与第 201 行超限提示；金额修改和异常组合还完成了保存为 XLSX、关闭重开的检查。v0.3 最终文件的副本也已实际打开、强制重算并保存，计算结果与预期一致。
